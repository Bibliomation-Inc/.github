# Bibliomation Inc.

Connecticut’s largest library consortium — and the state’s only open‑source consortium. We share an Evergreen ILS with member libraries and publish tools, scripts, and documentation for the wider community.

## Contributing

We welcome community fixes and improvements.

1. **Open an issue** in the relevant repository with context and steps to reproduce (if applicable).
2. **Fork** the repo and create a feature branch.
3. **Submit a PR** with a concise description (screenshots/log snippets encouraged when relevant).
4. A maintainer will review and provide feedback.

> Tip: Keep changes scoped and testable. If you’re unsure where to start, look for `good first issue` / `help wanted` labels.
