# Bibliomation Inc.

**Connecticut's largest library consortium — and the state's only open‑source consortium.**

We share an Evergreen ILS with member libraries and publish tools, scripts, and documentation for the wider community.

[Website](https://biblio.org) · [Docs](https://docs.biblio.org) · [Legacy Docs](https://biblio.org/documentation) · [Internship](https://bibliomation-inc.github.io/internship)

## 🔍 What You'll Find Here

- 🛠️ **Tools & Scripts** — Integrations with Evergreen ILS (data extracts, utilities, small services)
- 📖 **Public Documentation** — Resources for interns and partners
- 🔄 **Reusable Workflows** — Examples for open‑source library technology

## 🤝 Contributing

We welcome community fixes and improvements!

1. Open an issue in the relevant repository with context and steps to reproduce.
2. Fork the repo and create a feature branch.
3. Submit a PR with a concise description (screenshots/log snippets encouraged).
4. A maintainer will review and provide feedback.

> 💡 **Tip:** Keep changes scoped and testable. Look for `good first issue` / `help wanted` labels to get started!
